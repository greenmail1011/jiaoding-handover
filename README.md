# 教定區承接問答與分析（公開版）

幫新接手的人快速知道「過去怎麼做」的小工具。

- `index.html`：用瀏覽器打開（亮色系）。有三個分頁：
  - 🏢 辦公室：3D Q 版角色在直的狹長形辦公室裡工作（經理在最前面正中間，右邊區中心、總務、志工，左邊道務、教育），會坐著打字、走動、倒水、找人聊天、到經理桌前開會；拖曳旋轉、滾輪縮放，點角色就進入問答。
  - 💬 問答：點人物或打字、用語音輸入，會顯示過去的做法與出處日期。
  - 📊 分析：人物檔案卡、每月活動圖表、年度工作時間軸、人物關係圖（圖表已內嵌，離線可用）。
- `承接手冊_做法版.md`：同樣內容的文字版手冊，涵蓋 2017-10 至 2026-11 的群組訊息（第七節是 2017–2022 的補充）。

## 隱私處理

- 人名中間的字已用「小」遮蔽（例如 林小慧）。
- 不含原始對話、電話、帳號密碼、金額。
- 內容整理自群組訊息，是「過去的做法」，不是本人說的話。日期每年會變，請以當年公文為準。
- 人物圖像是依職務畫的原創角色，不是本人長相。
